# Honkai: Star Rail — All Light Cones (S1 Full Ability)

> อ้างอิงหลัก: [Game8 — All Light Cones](https://game8.co/games/Honkai-Star-Rail/archives/406599), [Fandom Wiki — Light Cone List](https://honkai-star-rail.fandom.com/wiki/Light_Cone/List)
> ข้อมูล ณ Version 4.5 (กันยายน 2026)
> Effect ที่แสดงเป็น **Superimposition Rank 1 (S1)** เท่านั้น — S2–S5 จะสเกลตัวเลขขึ้นตามลำดับ (ปกติ +25% ต่อ rank)

## หมายเหตุการอ่าน

- **Path** = สาย/บทบาทของ Light Cone (ต้องตรงกับ Path ของตัวละครถึงจะได้ passive)
- **Rarity**: 3★, 4★, 5★
- **Base stats (Lv.80)**: 5★ = HP 1058–1164 / ATK 476–635 / DEF 330–595; 4★ ต่ำกว่า ~15%; 3★ ต่ำกว่า ~30%
- **Superimpose Scaling**: ตัวเลข % หรือ flat value ใน passive จะเพิ่มขึ้นตามระดับ Superimposition (S1 → S5) ประมาณ +25% ต่อ rank (บางใบ +20%)
